Handbook Assistant Customer support agent

A support agent that answers student questions from the CS and IS department handbooks. When it can't answer confidently, it hands the question to a human advisor instead of guessing. It also gets better from the questions advisors answer.

  • Three separate judges. One LLM judge each for context relevance, faithfulness and answer relevance decides when to escalate. The model is never asked to rate its own confidence. If a judge breaks, the question goes to a human.
  • Tickets that survive a restart. Escalating ends the agent run. An advisor can answer hours later, and the reply goes back into the same conversation through its thread_id. Every status change is logged, and two advisors can't overwrite each other's work.
  • A learning loop the advisor controls. An advisor's answer joins the knowledge base only when the advisor chooses to add it. Handbook text always ranks first, and an answer that contradicts the handbook is held for review.
  • Built to run in production. Docker Compose, nginx, Alembic migrations, structured logs you can follow per conversation, Prometheus and Grafana with custom metrics, and 7 alert rules.

Mizan ميزان Egyptian labor law assistant

A legal assistant that answers questions about Egyptian labor law in Arabic and English and cites the articles it used. The name means "balance" in Arabic.

  • Corrective RAG loop. It grades each retrieved passage. If the results are weak, it rewrites the question in more precise legal terms and searches again, so answers come only from relevant legal text.
  • Arabic and English search. multilingual-e5-large embeddings in ChromaDB, and it replies in the language of the question.
  • Memory across sessions. LangGraph Store and Trustcall remember each user's name, profession and preferences, and adjust Mizan's instructions for that user based on their feedback.
  • Streaming and deployed. Answers stream as they're written, it works with LangGraph Studio, and it runs on Hugging Face Spaces.
